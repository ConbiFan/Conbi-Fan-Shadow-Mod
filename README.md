# Conbi Fan Shadow Mod

A Cookie Clicker mod that adds a custom Shadow Achievement system with persistent tracking and visual enhancements.

This project is designed for browser-based Cookie Clicker using GitHub Pages for distribution.

---

## 🌐 What is this?

This mod extends Cookie Clicker by adding additional achievements that track specific in-game behaviors over long-term play.

It does not modify core game logic or replace existing content.

---

## ⚙️ Features

- Custom Shadow Achievement tracking system  
- Persistent save using browser storage  
- Lightweight and performance-friendly  
- Uses original Cookie Clicker asset style  
- Fully browser-based (no installation required)
